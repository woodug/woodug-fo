# 우덕 (woodug)

KBO 팬들이 직관(직접 관람) 기록을 저장·분석할 수 있는 서비스

---

## 프로젝트 개요

| 항목        | 내용                                            |
| ----------- | ----------------------------------------------- |
| 프로젝트명  | 우덕 (woodug)                                   |
| 저장소      | woodug-fo (프론트엔드)                          |
| 기술 스택   | Next.js 14+, React 19, TypeScript, Tailwind CSS |
| 목적        | KBO 팬의 직관 기록 저장·분석·공유               |
| 타겟 사용자 | KBO 팬, 직관 경험을 기록·공유하고 싶은 사용자   |

---

## 기능 명세

### 1. 회원 기능

| 기능     | 설명                  |
| -------- | --------------------- |
| 회원가입 | 이메일 기반 계정 생성 |
| 로그인   | 가입 계정으로 인증    |
| 로그아웃 | 로그인 상태 해제      |

---

### 2. KBO 일정

| 기능           | 설명                  |
| -------------- | --------------------- |
| 경기 일정 조회 | 날짜별 경기 목록 확인 |
| 팀 순위 조회   | 현재 리그 순위 확인   |

---

### 3. 직관 기록

| 기능           | 설명                  |
| -------------- | --------------------- |
| 직관 등록      | 관람한 경기 기록 작성 |
| 직관 수정      | 작성한 기록 수정      |
| 직관 삭제      | 기록 삭제             |
| 직관 상세 조회 | 단건 기록 상세 확인   |

---

### 4. 사진 업로드

| 기능      | 설명                  |
| --------- | --------------------- |
| 사진 등록 | 직관 기록에 사진 첨부 |
| 사진 삭제 | 첨부된 사진 제거      |

---

### 5. 직관 통계

| 기능        | 설명                        |
| ----------- | --------------------------- |
| 전체 통계   | 총 직관 횟수 등 종합 수치   |
| 팀별 통계   | 응원 팀·상대 팀별 직관 집계 |
| 구장별 통계 | 방문한 구장별 집계          |
| 요일별 통계 | 요일별 직관 패턴 분석       |
| 월별 통계   | 월별 직관 횟수 추이         |

---

### 6. 마이 페이지

| 기능             | 설명                          |
| ---------------- | ----------------------------- |
| 프로필 조회·수정 | 닉네임, 프로필 이미지 등 변경 |
| 직관 목록 조회   | 내가 기록한 직관 전체 확인    |

---

### 7. 알림

| 기능           | 설명                        |
| -------------- | --------------------------- |
| 경기 시작 알림 | 관심 경기 시작 전 알림 수신 |

---

## 미확정 사항

추후 논의·결정이 필요한 항목입니다.

- **소셜 로그인** — 카카오·네이버 등 OAuth 지원 여부
- **알림 전달 방식** — 푸시 알림 / 인앱 알림 / 이메일 중 선택
