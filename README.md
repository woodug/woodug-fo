# 우덕 (woodug)

KBO 팬들이 직관(직접 관람) 기록을 저장·분석하고 친구들과 공유할 수 있는 서비스

---

## 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | 우덕 (woodug) |
| 저장소 | woodug-fo (프론트엔드) |
| 기술 스택 | Next.js 14+, React 19, TypeScript, Tailwind CSS |
| 목적 | KBO 팬의 직관 기록 저장·분석·공유 |
| 타겟 사용자 | KBO 팬, 직관 경험을 기록·공유하고 싶은 사용자 |

---

## 미확정 사항

추후 논의·결정이 필요한 항목입니다.

- **배지 지급 조건** — 어떤 기준(횟수, 구장, 팀 등)으로 배지를 부여할지
- **친구 피드** — 친구의 직관 기록을 열람하는 기능 포함 여부
- **소셜 로그인** — 카카오·네이버 등 OAuth 지원 여부
- **알림 전달 방식** — 푸시 알림 / 인앱 알림 / 이메일 중 선택
